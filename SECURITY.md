# Security policy

Don't open a public issue for a vulnerability. Email **<developers@smswithoutborders.com>** with:

- a description of the issue and its impact;
- the affected versions or commits;
- steps to reproduce it.

This covers the Publisher, its adapter SDK in `sdk/` and the platform adapters in the [smswithoutborders](https://github.com/smswithoutborders) organization.
