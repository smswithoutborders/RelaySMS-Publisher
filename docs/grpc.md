## Prerequisites

### Install Dependencies

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

For other languages, see [Supported languages](https://grpc.io/docs/languages/).

```bash
python -m grpc_tools.protoc -I protos/v3 --python_out=. --grpc_python_out=. protos/v3/publisher.proto
```

### Starting the Server

```bash
GRPC_PORT=<your_port> \
GRPC_HOST=<your_host> \
python3 grpc_server.py
```

## Version 3 API

**Package:** `publisher.v3`  
**Service:** `Publisher`

### v3 Request Headers

All v3 RPC calls require the following headers:

| Header | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `x-payload-bin` | bytes | Yes | Encrypted request payload ciphertext (binary) |
| `x-public-key-bin` | bytes | Yes | Client ephemeral public key ($eC_{pk}$, 32 bytes, binary) |
| `x-key-id` | string | Yes | Server static key ID used for encrypting the payload |
| `x-nonce-bin` | bytes | Yes | Request nonce (16 bytes, binary) |
| `x-timestamp` | string | Yes | Unix timestamp in seconds |

> [!NOTE]
> Headers ending in `-bin` are treated as binary metadata and expect raw binary data.

### v3: Get OAuth2 Authorization URL

Generates an OAuth2 authorization URL for initiating the OAuth2 flow.

**Request:** `GetOAuth2AuthorizationUrlRequest`

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| platform | string | Yes | Platform identifier (e.g., "gmail") |
| state | string | Optional | State parameter to prevent CSRF attacks |
| code_verifier | string | Optional | Cryptographic random string for PKCE |
| autogenerate_code_verifier | bool | Optional | Auto-generate code verifier if not provided |
| redirect_url | string | Optional | Redirect URL for OAuth2 application |
| request_identifier | string | Optional | Request identifier for tracking |

**Response:** `GetOAuth2AuthorizationUrlResponse`

| Field | Type | Description |
| :--- | :--- | :--- |
| authorization_url | string | Generated authorization URL |
| state | string | State parameter from request |
| code_verifier | string | Code verifier used in PKCE flow |
| message | string | Response message |
| scope | string | Authorization request scope |
| client_id | string | OAuth2 application client ID |
| redirect_url | string | OAuth2 application redirect URL |

**Example:**

```bash
grpcurl -plaintext \
  -H 'x-payload-bin: <encrypted_payload_binary>' \
  -H 'x-public-key-bin: <client_pk_binary>' \
  -H 'x-key-id: <key_id>' \
  -H 'x-nonce-bin: <nonce_binary>' \
  -H 'x-timestamp: <timestamp>' \
  -d '{
    "platform": "gmail",
    "autogenerate_code_verifier": true
  }' \
  -proto protos/v3/publisher.proto \
  <your_host>:<your_port> publisher.v3.Publisher/GetOAuth2AuthorizationUrl
```

### v3: Exchange OAuth2 Code and Store Token

Exchanges an OAuth2 authorization code for tokens and stores them. Returns encrypted token data and a set of server ephemeral keys.

**Request:** `ExchangeOAuth2CodeAndStoreRequest`

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| platform | string | Yes | Platform identifier |
| authorization_code | string | Yes | OAuth2 authorization code |
| code_verifier | string | Optional | Code verifier for PKCE |
| redirect_url | string | Optional | Redirect URL for OAuth2 application |
| request_identifier | string | Optional | Request identifier for tracking |
| client_ephemeral_public_keys | list[PublicKey] | Yes | Exactly 256 ephemeral public keys generated by the client |

**PublicKey Message:**

| Field | Type | Description |
| :--- | :--- | :--- |
| key_id | uint32 | Key index (0-255) |
| public_key | bytes | 32-byte public key |

**Response:** `ExchangeOAuth2CodeAndStoreResponse`

| Field | Type | Description |
| :--- | :--- | :--- |
| success | bool | Operation success |
| message | string | Response message |
| account_identifier | string | Account identifier (e.g., <mail@example.com>) |
| token_ciphertext | bytes | Encrypted token ciphertext |
| token_id | uint32  | Unique identifier for the stored token |
| server_ephemeral_public_keys | list[PublicKey] | Exactly 256 ephemeral public keys generated by the server |

**Example:**

```bash
grpcurl -plaintext \
  -H 'x-payload-bin: <encrypted_payload_binary>' \
  -H 'x-public-key-bin: <client_pk_binary>' \
  -H 'x-key-id: <key_id>' \
  -H 'x-nonce-bin: <nonce_binary>' \
  -H 'x-timestamp: <timestamp>' \
  -d @ \
  -proto protos/v3/publisher.proto \
  <your_host>:<your_port> publisher.v3.Publisher/ExchangeOAuth2CodeAndStore <<EOF
{
  "platform": "gmail",
  "authorization_code": "auth_code",
  "client_ephemeral_public_keys": [
    {"key_id": 0, "public_key": "..."},
    ... 254 more keys ...
    {"key_id": 255, "public_key": "..."}
  ]
}
EOF
```

### v3: Sync Keys

Syncs the client and server ephemeral key pools for a token. It rotates the client's key pool with a new set of 256 client ephemeral public keys, and the server generates a new pool of 256 server ephemeral keys.

**Request:** `SyncKeysRequest`

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| token_id | uint32 | Yes | Unique identifier for the stored token |
| key_id | uint32 | Yes | The current key index used for encrypting the token |
| client_ephemeral_public_keys | list[PublicKey] | Yes | Exactly 256 new ephemeral public keys generated by the client |

**Response:** `SyncKeysResponse`

| Field | Type | Description |
| :--- | :--- | :--- |
| success | bool | Operation success |
| message | string | Response message |
| server_ephemeral_public_keys | list[PublicKey] | Exactly 256 ephemeral public keys generated by the server |

**Example:**

```bash
grpcurl -plaintext \
  -H 'x-payload-bin: <encrypted_payload_binary>' \
  -H 'x-public-key-bin: <client_pk_binary>' \
  -H 'x-key-id: <key_id>' \
  -H 'x-nonce-bin: <nonce_binary>' \
  -H 'x-timestamp: <timestamp>' \
  -d @ \
  -proto protos/v3/publisher.proto \
  <your_host>:<your_port> publisher.v3.Publisher/SyncKeys <<EOF
{
  "token_id": 2941967295,
  "key_id": 123,
  "client_ephemeral_public_keys": [
    {"key_id": 0, "public_key": "..."},
    ... 254 more keys ...
    {"key_id": 255, "public_key": "..."}
  ]
}
EOF
```
