# gRPC API

The gRPC API links and unlinks platform accounts and syncs ephemeral key pools. The RelaySMS app calls it while online.

## Protocol buffer file

```bash
curl -O -L https://raw.githubusercontent.com/smswithoutborders/RelaySMS-Publisher/main/protos/v3/publisher.proto
```

Package `publisher.v3`, service `Publisher`.

## Generate a client

Generate stubs with `protoc` for your [language](https://grpc.io/docs/languages/). For Python:

```bash
pip install grpcio-tools
python -m grpc_tools.protoc -I . --python_out=. --grpc_python_out=. publisher.proto
```

## Request headers

Every RPC needs these headers. Headers ending in `-bin` carry raw binary.

| Header | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `x-payload-bin` | bytes | Yes | Encrypted request payload ciphertext |
| `x-public-key-bin` | bytes | Yes | Client ephemeral public key ($eC_{pk}$, 32 bytes) |
| `x-key-id` | string | Yes | ID of the server identity key used to encrypt the payload |
| `x-nonce-bin` | bytes | Yes | Request nonce (16 bytes) |
| `x-timestamp` | string | Yes | Unix timestamp in seconds, within `NONCE_TTL_SECONDS` of the server's clock |

The examples use `-plaintext` against a local server; drop it for a server behind TLS on port 443.

## Methods

### Get OAuth2 authorization URL

Generates an OAuth2 authorization URL for initiating the OAuth2 flow.

**Request:** `GetOAuth2AuthorizationUrlRequest`

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| platform | string | Yes | Platform identifier, such as `gmail` |
| state | string | Optional | OAuth2 `state`, returned unchanged |
| code_verifier | string | Optional | PKCE code verifier |
| autogenerate_code_verifier | bool | Optional | Auto-generate code verifier if not provided |
| redirect_url | string | Optional | Redirect URL for OAuth2 application |
| request_identifier | string | Optional | Request identifier for tracking |

**Response:** `GetOAuth2AuthorizationUrlResponse`

| Field | Type | Description |
| :--- | :--- | :--- |
| authorization_url | string | Generated authorization URL |
| state | string | State parameter from request |
| code_verifier | string | Code verifier used in PKCE flow |
| message | string | Response message |
| scope | string | Authorization request scope |
| client_id | string | OAuth2 application client ID |
| redirect_url | string | OAuth2 application redirect URL |

**Example:**

```bash
grpcurl -plaintext \
  -H 'x-payload-bin: <encrypted_payload_binary>' \
  -H 'x-public-key-bin: <client_pk_binary>' \
  -H 'x-key-id: <key_id>' \
  -H 'x-nonce-bin: <nonce_binary>' \
  -H 'x-timestamp: <timestamp>' \
  -d '{
    "platform": "gmail",
    "autogenerate_code_verifier": true
  }' \
  -proto publisher.proto \
  <HOST>:<PORT> publisher.v3.Publisher/GetOAuth2AuthorizationUrl
```

### Exchange OAuth2 code and store token

Exchanges an OAuth2 authorization code for tokens and stores them. Returns encrypted token data and a set of server ephemeral keys.

**Request:** `ExchangeOAuth2CodeAndStoreRequest`

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| platform | string | Yes | Platform identifier |
| authorization_code | string | Yes | OAuth2 authorization code |
| code_verifier | string | Optional | Code verifier for PKCE |
| redirect_url | string | Optional | Redirect URL for OAuth2 application |
| request_identifier | string | Optional | Request identifier for tracking |
| client_ephemeral_public_keys | list[PublicKey] | Yes | Exactly 256 ephemeral public keys generated by the client, with key_id 0-255 each used once |

**PublicKey Message:**

| Field | Type | Description |
| :--- | :--- | :--- |
| key_id | uint32 | Key index (0-255) |
| public_key | bytes | 32-byte public key |

**Response:** `ExchangeOAuth2CodeAndStoreResponse`

| Field | Type | Description |
| :--- | :--- | :--- |
| success | bool | Operation success |
| message | string | Response message |
| account_identifier | string | Account identifier, such as `mail@example.com` |
| token_ciphertext | bytes | Encrypted token ciphertext |
| token_id | uint32  | Unique identifier for the stored token |
| server_ephemeral_public_keys | list[PublicKey] | Exactly 256 ephemeral public keys generated by the server |

**Example:**

```bash
grpcurl -plaintext \
  -H 'x-payload-bin: <encrypted_payload_binary>' \
  -H 'x-public-key-bin: <client_pk_binary>' \
  -H 'x-key-id: <key_id>' \
  -H 'x-nonce-bin: <nonce_binary>' \
  -H 'x-timestamp: <timestamp>' \
  -d @ \
  -proto publisher.proto \
  <HOST>:<PORT> publisher.v3.Publisher/ExchangeOAuth2CodeAndStore <<EOF
{
  "platform": "gmail",
  "authorization_code": "auth_code",
  "client_ephemeral_public_keys": [
    {"key_id": 0, "public_key": "..."},
    ... 254 more keys ...
    {"key_id": 255, "public_key": "..."}
  ]
}
EOF
```

### Get PNBA code

Requests a one-time passcode (OTP) for Phone Number-Based Authentication.

**Request:** `GetPNBACodeRequest`

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| platform | string | Yes | Platform identifier |
| phone_number | string | Yes | Phone number to receive OTP |
| request_identifier | string | Optional | Request identifier for tracking |
| channel | string | Optional | Channel to send the code over, such as `whatsapp`, `telegram` or `signal` |

**Response:** `GetPNBACodeResponse`

| Field | Type | Description |
| :--- | :--- | :--- |
| success | bool | Operation success |
| message | string | Response message |
| expires_at | int64 | Optional. Code expiry, Unix epoch seconds |

**Example:**

```bash
grpcurl -plaintext \
  -H 'x-payload-bin: <encrypted_payload_binary>' \
  -H 'x-public-key-bin: <client_pk_binary>' \
  -H 'x-key-id: <key_id>' \
  -H 'x-nonce-bin: <nonce_binary>' \
  -H 'x-timestamp: <timestamp>' \
  -d '{
    "platform": "telegram",
    "phone_number": "+1234567890"
  }' \
  -proto publisher.proto \
  <HOST>:<PORT> publisher.v3.Publisher/GetPNBACode
```

### Sync keys

Replaces a token's key pools: the client sends 256 new ephemeral public keys and the server returns 256 of its own.

**Request:** `SyncKeysRequest`

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| token_id | uint32 | Yes | Unique identifier for the stored token |
| key_id | uint32 | Yes | The current key index used for encrypting the token |
| client_ephemeral_public_keys | list[PublicKey] | Yes | Exactly 256 new ephemeral public keys generated by the client, with key_id 0-255 each used once |

**Response:** `SyncKeysResponse`

| Field | Type | Description |
| :--- | :--- | :--- |
| success | bool | Operation success |
| message | string | Response message |
| server_ephemeral_public_keys | list[PublicKey] | Exactly 256 ephemeral public keys generated by the server |

**Example:**

```bash
grpcurl -plaintext \
  -H 'x-payload-bin: <encrypted_payload_binary>' \
  -H 'x-public-key-bin: <client_pk_binary>' \
  -H 'x-key-id: <key_id>' \
  -H 'x-nonce-bin: <nonce_binary>' \
  -H 'x-timestamp: <timestamp>' \
  -d @ \
  -proto publisher.proto \
  <HOST>:<PORT> publisher.v3.Publisher/SyncKeys <<EOF
{
  "token_id": 2941967295,
  "key_id": 123,
  "client_ephemeral_public_keys": [
    {"key_id": 0, "public_key": "..."},
    ... 254 more keys ...
    {"key_id": 255, "public_key": "..."}
  ]
}
EOF
```
